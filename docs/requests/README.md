# Cross-area requests

Copy TEMPLATE.md to `CR-<area>-<task>-<short-topic>.md`, push the feature branch, and add a live board note containing the branch/PR and file path. One steward edits a shared contract at a time. Requests are proposals until the impacted owners review them.

States: proposed → acknowledged → accepted/rejected → implemented → verified. Name real owners; do not invent acknowledgements. Read open requests at session start and before integration. Long discussions live in the request or PR; the single TASKS.md board indexes the latest decision/blocker. Private data never belongs in request files.
